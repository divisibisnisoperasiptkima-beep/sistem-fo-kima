CONTRACT-04 — Upgrade paket dari 1 Core ke 2 Core

Hasil retest: Lulus.

Temuan awal berupa HTTP 500 saat tanggal upgrade sama dengan awal kontrak telah diperbaiki. Form kini menetapkan tanggal minimum satu hari setelah periode awal; backend juga menolak request yang tidak valid dengan HTTP 400 dan pesan yang jelas, tanpa mengubah data kontrak.

DRIVE-01 sampai DRIVE-03 — Verifikasi integrasi Google Drive

Hasil: Lulus.

Folder pelanggan dan periode kontrak berhasil dibuat. Dokumen uji kategori Kontrak dapat dibuka langsung di Google Drive. Setelah dihapus melalui aplikasi (HTTP 204), tautan file mengembalikan halaman tidak ditemukan (HTTP 404), sehingga penghapusan pada Drive terverifikasi.

7. Cleanup dan Keputusan

  • Dokumen UAT dihapus dari Drive dan database.
  • Titik lokasi UAT dihapus.
  • Kontrak UAT, hasil perpanjangan, hasil upgrade Sharing Core, dokumen/folder Drive, dan pelanggan UAT dihapus. Pencarian akhir tidak menemukan data UAT.
  • Akun Teknisi UAT dipertahankan dalam status nonaktif sesuai audit trail aplikasi.
